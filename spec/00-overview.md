# 00. Обзор

Черновик. Описывает Shum Protocol v1, как он работает в iOS-приложении 1.0.

## Что такое Shum с точки зрения протокола

Shum это мессенджер без номера телефона и без центрального сервера переписки.
У каждого человека есть **личность**: набор ключей, созданных на устройстве.
Люди обмениваются **карточками контакта** (через QR-код, ссылку или Bluetooth
рядом) и дальше переписываются **конвертами**, зашифрованными для получателя.

Конверт доставляется одним из двух **транспортов**:

| Транспорт | Когда | Что внутри |
|---|---|---|
| Bluetooth LE | люди рядом, без интернета | сетка Bitchat: прямые соединения, Noise-сессии, пересылка через других |
| Nostr | есть интернет | события на открытых релеях, содержимое зашифровано |

Дополнительно есть **push-сервер**: он будит приложение получателя, когда для
него лежит событие на релее. Переписку он не видит.

## Сущности

| Сущность | Раздел | Коротко |
|---|---|---|
| Личность | [01](01-keys-identity.md) | три пары ключей: Noise (X25519), подпись (Ed25519), Nostr (secp256k1) |
| Shum ID | [01](01-keys-identity.md) | SHA-256 от Noise-ключа, 64 hex-символа |
| Карточка контакта | [02](02-contact-card.md) | публичные ключи, имя, «О себе», семя пиксельного аватара, подписи |
| Приглашение | [02](02-contact-card.md) | карточка, упакованная в ссылку `shum://c4/...` или `https://.../invite#c4/...` |
| Конверт | 03 | сообщение, запечатанное на постоянный Noise-ключ получателя |
| Пакет | 04 | вид содержимого конверта: сообщение, отметка, приглашение, «печатает», присутствие, профиль, удаление, реакция |
| Правила | 05 | кого принимать, как убирать дубли, кто побеждает при конфликте |

## Модель одного устройства

В версии 1 у личности **одно устройство-писатель**. Одновременная работа с
нескольких устройств с общими закрытыми ключами не поддерживается
(`docs/seed-profile-protocol.md`). Связанные устройства запланированы в
протоколе v2: у каждого устройства свой ключ, профиль подтверждает свои
устройства.

## Происхождение кода

Bluetooth-сетка, Noise-сессии, курьерская упаковка и модели пакетов взяты из
открытого проекта **Bitchat** (Unlicense) и доработаны в Shum. Ревизия Bitchat
указана в `Shum-iOS/Upstreams/versions.json`. Где поведение совпадает с
Bitchat, спецификация всё равно описывает его полностью, чтобы совместимый
клиент не зависел от чужого репозитория.

## Общие соглашения

- Все многобайтовые целые в двоичных форматах указываются явно: где-то
  little-endian, где-то big-endian. Порядок байтов всегда пишется рядом с полем.
- `hex` означает строчные шестнадцатеричные символы без префикса `0x`.
- `base64` означает стандартный алфавит с дополнением `=`.
  `base64url` означает алфавит `-` и `_` вместо `+` и `/`, **без** дополнения.
- Строки текста это UTF-8 без нормализации Unicode. Байты, которые пришли,
  сохраняются как есть.
- Строки с нулевым байтом в конце, например `"shum.profile.v1\0"`, это
  **метки домена**: они добавляются в начало подписываемых данных, чтобы
  подпись одного вида нельзя было выдать за подпись другого.

## Версии

| Что | Где задаётся | Сейчас |
|---|---|---|
| Версия карточки | поле `version` в карточке | `1`, другие значения отклоняются |
| Формат приглашения | байт формата в начале данных | `1`, `3`, `4` (см. раздел 02) |
| Генератор пиксельного аватара | поле `avatarVersion` | `1` |
| Метки домена | суффикс `.v1` в метке | `v1` |

Правило «новые поля не ломают старых клиентов» будет описано вместе с
переходом на v2.
